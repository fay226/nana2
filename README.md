# Fiona’s portfolio

Open index.html in Chrome or Safari after extracting the project. Keep style.css, script.js, and assets/ beside it. No installation needed.

The 15 original Procreate PNGs in assets/ all share a 1440 × 900 canvas. They are stacked without cropping or changing their positions. Transparent images do not receive pointer events; tight hit areas provide the six links. A single contain scale resizes the entire scene without distortion.

Hover or focus the book, cup, compass, bracelet, painting, or envelope. The labels and effects reveal; clicking navigates to the matching page section. Touch devices show labels and effects. Reduced-motion preferences disable animation.

The laptop is painted into room-background.png, so it remains static. Page background is white; colours within the supplied room illustration are retained unchanged.

DESIGN.md contains the current visual rules and exact typography chart. The project section remains a provisional layout. Local HTML, image references, original file hashes, and shared-scaling checks passed; browser interaction testing remains pending sign-in.
