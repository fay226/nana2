# Contact envelope PNG assets

These five files are starter illustrations to make the Contact section work without broken images. Replace them with your own Procreate drawings when ready.

- `envelope-flap.png` — triangular folding back flap, shown inside the CSS flap mask.
- `envelope-front.png` — front pocket overlay, shown inside the CSS front mask.
- `envelope-letter.png` — rising letter paper background.
- `linkedin.png` — clickable LinkedIn icon artwork.
- `gmail.png` — clickable email icon artwork.

All files have transparent backgrounds. Keep the same filenames. The CSS slots crop/stretch their contents into the envelope animation. For highest accuracy, export the flap, front and letter as separately cropped transparent images, not full-scene images; alternatively adjust the `.contact-envelope-*` CSS offsets to match your artwork.

The link destinations are already configured in `script.js`. The hover/tap interaction remains the same.

**These illustrations are placeholders** and are not your original Procreate artwork.
